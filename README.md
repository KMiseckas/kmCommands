Experimenting with Spec-Driven AI development for a personal project while GH Copilot AI wasn't too expensive.
- GH Copilot
- Spec first, implement next workflow.
- Custom agents for various jobs. Jobs are handed down from requirement gathering, planning, designing, to implementation and analysis agents.
- Experimenting with agents, instruction, and skill files.

Didn't trust AI to solely decide everything across the whole project, I already have had experience in implementing a command system for Unity in C# (even if not brilliant) I had a good idea of the architecture and features required so I could guide AI effectively.
Reinforced correct behaviour with unit tests only for this project and a sample in Unity for integration. AI performed pretty decently when given a strongly outlined project, hard goals, and clear direction, however reviewing AI generated plans and designs is
a definite bore and eventually you kind of just agree that AI is probably 90% right. I ended up instead just skimming the plans making sure they look okay, and allowing AI to start implementing. Came to a conclusion (atleast for this project, that started from nothing)
that its easier to review the code written and see if it that matches to what I was thinking I would do if I were the one asked to implement the feature. 

Was a fun experiment, sitting back and letting it do most of the job, at the end of the day I would not be comfortable with letting this be production code without more serious intervention from myself, but I think there is a sweet spot for AI + Human programming (pair programming).
